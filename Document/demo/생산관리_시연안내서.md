# 생산관리(반도체 후공정 외주) 시연 안내서

이 문서만 보고 화면을 따라가면 **웨이퍼 입고 → Bumping → EDS → Packaging → Final Test**까지 한 번에 돌려볼 수 있게 썼습니다.
각 단계마다 "어느 화면에서, 무엇을 누르고 입력하고, 그 결과 화면과 재고가 어떻게 되어야 하는지"를 적었습니다. 실제 화면과 다르게 나오면 그 단계가 어긋난 곳입니다.

---

## 0. 시작하기 전에

### 0-1. 준비

1. **WYNLAB.exe를 완전히 종료했다가 다시 실행**합니다. (새 화면 모듈은 앱을 시작할 때만 로드됩니다.)
2. 메뉴에서 **생산관리** 아래에 아래 화면이 보여야 합니다. 안 보이면 메뉴권한 화면에서 본인 계정에 권한을 부여하세요.

| 메뉴 경로 | 화면 |
|---|---|
| 생산관리 > 생산기준관리 > 공정관리 | 공정 마스터 |
| 생산관리 > 생산기준관리 > 라우팅관리 | 라우팅(공정 체인) |
| 생산관리 > 생산실행 > 작업지시 | 작업지시 |
| 생산관리 > 생산실행 > 웨이퍼입고 | 웨이퍼 도착(입고) 등록 |
| 생산관리 > 생산실행 > 공정실적 | 공정실적 |
| 생산관리 > 생산실행 > 외주이전 | 외주처 간 이전 |
| 생산관리 > 생산실행 > 작업지시현황 | 조회 |

3. 검증용으로 **자재/구매관리 > 재고관리 > 재고현황 / 수불현황**(frmStockList, frmTransList)을 같이 열어 두면 단계마다 재고 위치가 바뀌는 것을 확인할 수 있습니다.

### 0-2. 미리 넣어 둔 데이터

| 구분 | 내용 |
|---|---|
| 외주처 | TSMC(웨이퍼 공급), **Amkor**(Bumping / Packaging), **ITEK**(EDS / Final Test) |
| 창고 | **Amkor 창고**, **ITEK 창고**(외주처 재고), **이동중 재고**(이전 중인 물건) |
| 품목 | 웨이퍼(WF-RAW) → 범핑 웨이퍼(WF-BUMP) → Good Die(DIE-GOOD) → 패키지(PKG-RAW) → 완제품 패키지(PKG-FG) |
| 라우팅 | `DEMO-SWP` 반도체 후공정 (시연): 1 Bumping(Amkor) → 2 EDS(ITEK) → 3 Packaging(Amkor, 5,000개 분할) → 4 Final Test(ITEK) |
| 수주 | `SO26090001` [시연] 반도체 완제품 주문 — 시연고객(DEMO), 완제품 패키지 20,000 EA |
| 웨이퍼 재고 | LOT **W2609-02** 25장만 Amkor 창고에 미리 입고되어 있음(빠른 시연용, 작업지시에 아직 배정 안 된 상태). **W2609-01은 재고가 없음** - Step 1에서 웨이퍼입고 화면으로 직접 입고합니다. |
| 엑셀 샘플 | `D:\01. SOURCE\00. WYNLAB\Document\demo\EDS_W2609-01_wafer.xlsx` (EDS 웨이퍼 판정, 25장) |

> 이 안내서의 본 시나리오는 LOT **W2609-01**로 진행합니다(웨이퍼 입고부터). **W2609-02**는 재고가 이미 있어 웨이퍼 입고 없이 작업지시에서 바로 고를 수 있으므로, 3절의 응용 시나리오(수량 차이, 취소 등)나 처음부터 다시 해볼 때 쓰세요. 문서에 나오는 번호(WO26090001, RV26090001 등)는 예시이며, 이미 만들어 둔 문서가 있으면 일련번호가 다를 수 있습니다.

### 0-3. 흐름 한눈에 보기

```
[웨이퍼 LOT W2609-01, 25장]  (TSMC -> Amkor 직송)
   │  ① 웨이퍼입고 (품목/LOT/수량/창고 직접 입력 → Amkor 창고에 W2609-01 25장 재고, 작업지시 없이 먼저)
   │  ①-b 작업지시 ("LOT 선택"으로 입고된 LOT 배정 + 라우팅 복사 + 수주 연결) → 확정
   ▼
 ② Bumping 실적 (Amkor)       25장 → 범핑 웨이퍼 25장            LOT W2609-01-BUMP
   │  ③ 외주이전 1: Amkor → ITEK
   ▼
 ④ EDS 실적 (ITEK)            웨이퍼 25장 → Good Die 19,494개    LOT W2609-01-EDS   (엑셀 불러오기)
   │  ⑤ 외주이전 2: ITEK → Amkor
   ▼
 ⑥ Packaging 실적 (Amkor)     Good Die 19,494 → 패키지 19,400    LOT W2609-01-PKG01~04 (5,000개씩 분할)
   │  ⑦ 외주이전 3: Amkor → ITEK
   ▼
 ⑧ Final Test 실적 (ITEK)     패키지 → 완제품 패키지             LOT W2609-01-FT01~04
   ▼
 ⑨ 작업지시현황에서 확인 / 작업지시 완료
```

### 0-4. 화면 공통 사용법

- 화면 위 회색 줄은 **조회 조건**입니다. 번호를 넣고 툴바 **조회**를 누르면 그 문서가 열립니다. **번호를 비우고 조회하면 "신규 입력 상태로 전환했습니다"** 라는 안내와 함께 새 문서 입력 모드가 됩니다(정상 동작).
- **저장**은 툴바의 저장 버튼입니다. 확정/출발 확인 같은 단계 버튼은 **저장한 뒤에만** 활성화됩니다. 저장하지 않은 변경이 있으면 "먼저 저장하세요"라고 막습니다.
- 노란 배경 칸은 필수 입력입니다.
- 팝업(불러오기)은 체크박스로 행을 고르고 아래 **불러오기** 버튼을 누릅니다. 위쪽에서 날짜/번호/LOT로 다시 조회할 수 있습니다.
- 확정/취소 단계는 확인창이 뜹니다. **예**를 누르면 실행됩니다.
- **공정관리 / 라우팅관리는 위와 다른 "목록 화면"입니다.** 화면을 열면 목록이 자동으로 조회되고, **조회 조건을 비우면 전체 목록**입니다(신규로 전환되지 않음). 라우팅관리는 **왼쪽 목록에서 행을 클릭하면 오른쪽에 그 내용이 나타나고**, 저장하면 목록에 반영되어 방금 저장한 행이 그대로 선택됩니다. 저장하지 않은 변경이 있는 채로 다른 행을 클릭하면 확인창이 뜹니다. 왼쪽과 오른쪽 사이 경계는 마우스로 끌어 폭을 조절할 수 있습니다.

## 1. 본 시나리오 (LOT W2609-01)

### Step 0. 기준 데이터 확인 (선택, 2분)

**생산관리 > 생산기준관리 > 공정관리**
- 화면을 열면 목록이 자동으로 뜹니다(조건 비움 = 전체). 4행이 보여야 합니다: `BUMP Bumping / EDS EDS / PKG Packaging / FT Final Test` (정렬 1~4, 사용 체크).
- "사용중" 칸: 라우팅이 이 공정을 쓰고 있어 체크(Y)로 보입니다. 이 공정들은 삭제할 수 없습니다(사용여부를 끄는 방식).

**생산관리 > 생산기준관리 > 라우팅관리**
- 화면을 열면 **왼쪽 "라우팅 LIST"에 `DEMO-SWP 반도체 후공정 (시연)`** 한 행이 보이고, 자동으로 선택되어 오른쪽에 내용이 채워집니다. (안 채워져 있으면 그 행을 한 번 클릭하세요.)
- 오른쪽 위쪽: 라우팅코드 `DEMO-SWP`(저장된 코드라 수정 불가), 라우팅명 "반도체 후공정 (시연)", 완제품 "완제품 패키지", 사용 체크.
- 오른쪽 아래 공정 그리드 4행:

| 순번 | 공정 | 기본 외주처 | 투입품목 → 산출품목 | 단위 | 분할수량 |
|---|---|---|---|---|---|
| 1 | Bumping | Amkor | WF-RAW → WF-BUMP | SHT → SHT | (없음) |
| 2 | EDS | ITEK | WF-BUMP → DIE-GOOD | SHT → EA | (없음) |
| 3 | Packaging | Amkor | DIE-GOOD → PKG-RAW | EA → EA | **5,000** |
| 4 | Final Test | ITEK | PKG-RAW → PKG-FG | EA → EA | (없음) |

- 핵심: **앞 공정의 산출품목 = 다음 공정의 투입품목**입니다(공정마다 품목이 바뀌는 구조).

---

### Step 1. 웨이퍼 입고 (TSMC → Amkor 직송 도착 등록) — 작업지시보다 먼저

이 업체는 웨이퍼를 자사 창고에 들이지 않고 공급처(TSMC)에서 첫 공정 외주처(Amkor)로 **바로 보냅니다.** 웨이퍼가 Amkor에 도착하면, **작업지시가 없어도** 이 화면에서 품목/LOT/수량/창고를 직접 입력해 Amkor 창고에 재고를 만듭니다. 작업지시는 그 다음에 이 LOT를 골라 씁니다.

**생산관리 > 생산실행 > 웨이퍼입고** (왼쪽 "웨이퍼 입고 LIST", 오른쪽 입력 화면. 라우팅관리와 같은 목록 구조입니다.)

1. 툴바 **신규**(처음이면 목록이 비어 있어 이미 신규 상태입니다).
2. 아래 값을 입력합니다.

| 항목 | 입력값 |
|---|---|
| 사업장 / 입고일자 | 자동(본인 사업장 / 오늘) |
| 품목 | 돋보기 팝업에서 **WF-RAW(웨이퍼)** 선택 |
| LOT번호 | **W2609-01** |
| 입고수량(장) | **25** |
| 입고 창고 | 돋보기 팝업에서 **Amkor 창고** 선택 |
| 공급처 | (선택) **TSMC** |
| 배정 작업지시 | 읽기 전용 — 아직 비어 있음 |

3. **저장** → 왼쪽 목록에 입고번호(`RV` + 년월 + 일련번호, 예 `RV26090001`)가 생기고 상태는 **작성**.
4. **[입고 확정]** → 예.
   - 상태 **확정**. 재고: **Amkor 창고 `W2609-01` 25장이 생깁니다.** 아직 어느 작업지시에도 배정되지 않은 "미배정 LOT"입니다.
5. (참고) **부분 입고**도 됩니다. 같은 LOT 번호로 10장 + 15장처럼 두 번 등록·확정하면 LOT 수량이 25장으로 누적됩니다.
6. (참고) 필수값(품목/LOT번호/입고 창고/수량)이 비면 저장되지 않습니다. 확정을 잘못했다면 **[입고 확정취소]**로 되돌립니다.
   - 단, 그 LOT를 이미 작업지시에 배정했으면 추가 입고와 확정취소가 모두 막힙니다("이미 작업지시 ... 에 배정된 LOT입니다"). 작업지시를 삭제하면 배정이 풀립니다.

### Step 1b. 작업지시 등록 — 입고된 LOT 배정

**생산관리 > 생산실행 > 작업지시** → 툴바 **신규**(또는 번호 비운 채 조회)

| 항목 | 입력값 |
|---|---|
| 사업장 | 자동(본인 사업장) |
| 작업일자 | 자동(오늘) |
| 라우팅 | **반도체 후공정 (시연)** 선택 |
| 시작 LOT | **[LOT 선택]** 버튼 → 팝업에서 `W2609-01`(품목 웨이퍼, 재고 25, Amkor 창고) 체크 → **불러오기** → 시작 LOT와 시작수량 25가 채워집니다(직접 입력 불가) |
| 수주번호 | **[수주 선택]** 버튼 → 팝업에서 `SO26090001`(순번 1) 체크 → **불러오기** → 납기가 자동으로 채워집니다 |
| 부서 / 담당자 | 자동 |

- [LOT 선택] 팝업이 비어 있으면 하단 빨간 글씨 안내대로 **웨이퍼입고에서 입고 확정**을 먼저 하세요. 이미 다른 작업지시에 배정된 LOT는 나오지 않습니다. 라우팅 첫 공정 투입품목(웨이퍼)과 다른 품목의 LOT는 저장 시 거부됩니다.

1. **저장**을 누릅니다.
2. 기대 결과
   - 작업지시번호가 채번됩니다(`WO` + 년월 + 일련번호, 예 `WO26090001`), 진행상태 **계획**. (아래 5번에서 확정)
   - **공정별 외주 진행** 그리드에 공정 4행이 자동으로 생깁니다. 외주처는 Amkor / ITEK / Amkor / ITEK, **외주처 창고**는 Amkor 창고 / ITEK 창고 / Amkor 창고 / ITEK 창고. 분할수량 5,000은 Packaging 행에 보입니다.
   - **LOT 현황** 그리드에 `W2609-01`(생성 공정 0, 수량 25)이 Amkor 창고 / 현재고 25로 보입니다.
3. (선택) 공정행의 **가공단가 / 정산단위 / 납기**를 입력해 보세요. 예: Bumping 정산단위 SHT, 단가 1,500. 수정하고 **저장**합니다. (단가는 실제 값을 몰라 비워 두었습니다.)
4. 저장 후에는 라우팅 / 시작 LOT / 시작수량 칸이 잠깁니다(잘못 만들었으면 삭제 후 다시 작성 — 삭제하면 LOT 배정이 풀려 웨이퍼 재고는 그대로 남고 다시 고를 수 있습니다).
5. **[확정] 버튼을 누릅니다 → 예.** (오른쪽 위 버튼 줄: 확정 / 확정취소 · 중단 / 중단해제 · 완료 / 완료취소)
   - 진행상태가 **계획 → 확정**으로 바뀝니다. **확정해야 다음 단계(공정실적, 외주이전)를 진행할 수 있습니다.** 확정 전에는 실적을 저장하려 하면 "작업지시가 아직 확정되지 않았습니다"라고 막히고, 실적 대기 LOT 불러오기 목록에도 나오지 않습니다.
   - 시작 LOT에 재고가 있으므로 "재고가 아직 없습니다" 경고는 뜨지 않습니다.
   - 공정마다 외주처/창고가 지정되어 있어야 확정됩니다(라우팅에서 복사되므로 시연에서는 문제없음).
   - 실수로 확정했다면 **확정취소**로 계획 상태로 되돌릴 수 있습니다(실적/이전이 시작되기 전에만).

> 작업지시 상태 흐름: **계획 → 확정 → 진행**(첫 실적을 확정하면 자동) **→ 완료**(완료 버튼), 중간에 **중단**(확정/진행 상태에서만)할 수 있습니다.

> 확인 포인트: 작업지시를 만들거나 확정해도 **재고는 변하지 않습니다**(Amkor 창고 W2609-01 = 25 그대로). 재고는 Step 1 웨이퍼 입고에서 생겼고, 다음 단계 Bumping 실적에서 차감됩니다.

### Step 2. Bumping 실적 (Amkor)

**생산관리 > 생산실행 > 공정실적** → **신규**

> 먼저 Step 1에서 웨이퍼를 **입고 확정**하고 Step 1b에서 작업지시를 **확정**해 두어야 아래 팝업에 나옵니다. 팝업이 비어 있으면 하단 빨간 글씨의 안내를 보세요.

1. **[실적 대기 LOT 불러오기]** 클릭 → 팝업이 뜹니다.
   - 위쪽 작업일자 범위에 오늘이 포함되어 있는지 확인하고 **조회**.
   - 목록에서 아래 행을 체크합니다(한 건만 선택 가능).

   | 작업지시 | 순번 | 공정 | 외주처 | 투입 LOT | 현재고 | 산출품목 |
   |---|---|---|---|---|---|---|
   | WO26090001 | 1 | Bumping | Amkor | **W2609-01** | 25 | 범핑 웨이퍼 |

   → **불러오기**.

- 작업지시의 공정행에서 **외주처를 바꾸면** 그 외주처의 외주창고가 자동으로 지정됩니다(실적/이전이 시작된 공정은 못 바꿈).

### E. 라우팅을 새로 만들어 보기 (라우팅관리 화면 사용법 연습)

1. **라우팅관리**에서 툴바 **신규** → 오른쪽이 비워지고 커서가 입력칸으로 갑니다(왼쪽 목록의 선택은 그대로).
2. 라우팅코드 `TEST-RT`, 라우팅명 `테스트 라우팅`, 완제품은 돋보기 팝업에서 `완제품 패키지` 선택.
3. 공정 그리드에서 **행추가** → 순번 1이 자동으로 들어갑니다. 공정 콤보에서 `Bumping`, 기본 외주처 팝업에서 `Amkor`, 투입품목 `웨이퍼`, 산출품목 `범핑 웨이퍼`를 고르면 **투입/산출 단위(SHT)가 자동으로 채워집니다**.
4. 다시 **행추가** → 순번 2, 공정 `EDS`, 외주처 `ITEK`, 투입품목을 앞 행의 산출품목이 아닌 다른 것(예: `패키지`)으로 넣어 보세요.
5. **저장** → "1번 공정의 산출품목과 2번 공정의 투입품목이 다릅니다. 그래도 저장하시겠습니까?" 경고가 뜹니다(연결이 끊겼다는 안내, **아니오**를 누르고 투입품목을 `범핑 웨이퍼`로 고친 뒤 다시 저장).
6. 저장되면 **왼쪽 목록에 `TEST-RT`가 새로 나타나고 선택된 상태**이며, 라우팅코드 칸은 읽기전용으로 바뀝니다.
7. 목록에서 `DEMO-SWP`를 클릭했다가 다시 `TEST-RT`를 클릭해 보세요. 오른쪽 내용이 그때그때 바뀝니다. (편집 중 저장 안 한 채로 다른 행을 클릭하면 확인창이 뜹니다.)
8. `TEST-RT`를 선택하고 툴바 **삭제** → 확인창 **예** → 목록에서 사라집니다. (작업지시에서 쓰지 않은 라우팅만 삭제됩니다.)

## 5. 자주 나오는 안내/오류와 원인

| 메시지 | 원인 / 조치 |
|---|---|
| "먼저 저장한 뒤 확정하세요" | 신규 문서를 저장하지 않고 확정/출발 버튼을 눌렀습니다. 저장부터. |
| "작업지시가 아직 확정되지 않았습니다" | 작업지시가 계획 상태입니다. 작업지시 화면에서 **확정** 버튼을 누르세요. |
| "'LOT 선택'으로 입고된 웨이퍼 LOT를 선택하세요" | 작업지시 저장 전에 [LOT 선택]을 하지 않았습니다. 먼저 웨이퍼입고에서 입고 확정 후 선택하세요. |
| 작업지시 [LOT 선택] 팝업이 비어 있음 | 웨이퍼입고를 확정하지 않았거나, 이미 다른 작업지시에 배정된 LOT입니다(하단 빨간 글씨 안내). |
| 웨이퍼입고 저장 시 필수 입력 안내 | 품목 / LOT번호 / 입고 창고 / 수량(0보다 커야 함)을 입력하세요. |
| 웨이퍼입고 "배정된 LOT" 거부 | 그 LOT를 이미 작업지시에 배정했습니다. 추가 입고/확정취소는 작업지시를 삭제(배정 해제)한 뒤 가능합니다. |
| "시작 LOT ... 재고가 아직 없습니다" (작업지시 확정 때) | 선택한 LOT의 재고가 첫 공정 외주처 창고에 없습니다(입고 확정취소 등). 웨이퍼입고를 다시 확인하세요. |
| "저장하지 않은 변경이 있습니다" | 확정/출발/도착 전에 저장하세요. |
| 불러오기 팝업이 비어 있음 (하단 빨간 글씨에 원인 안내가 나옵니다) | ① **작업지시가 "확정" 상태인지**(계획 상태는 안 나옵니다) ② **투입 LOT가 그 공정 외주처 창고에 재고로 있는지** - 시작 LOT 번호를 웨이퍼 재고와 다르게 입력했으면(예: 웨이퍼입고 없이 재고가 없는 LOT) 재고가 없어 나오지 않습니다. 웨이퍼입고에서 입고 확정한 LOT로 작업지시를 만드세요. ③ 앞 단계(이전 도착 확인 / 실적 확정)를 했는지, 날짜 범위에 작업일이 포함되는지 확인하세요. |
| "이전 대상 LOT 불러오기"에 LOT가 안 보임 | 그 LOT가 출발 외주처 창고에 재고로 있어야 합니다(실적 확정 후). |
| "양품+불량 수량이 투입수량을 넘을 수 없습니다" | 같은 단위 공정(Bumping/Packaging/Final Test)은 양품+불량 ≤ 투입수량. |
| "현재고가 부족합니다..." | 그 LOT가 이미 소진/이동되었습니다(취소 순서 또는 수량 확인). |
| "같은 작업지시, 같은 공정 구간의 LOT만..." | 이전 팝업에서 서로 다른 구간을 같이 체크했습니다. |
| 작업지시 저장 시 LOT 관련 거부 | 이미 배정된 LOT이거나 라우팅 첫 공정 투입품목과 품목이 다릅니다. 다른 LOT/라우팅을 선택하세요. |
| "끝나지 않은 외주 이전이 있어 완료할 수 없습니다" | 지시/이동중/도착(차이대기) 상태의 이전 문서를 마무리하세요. |
| 메뉴가 안 보임 | 앱 재시작 후에도 없으면 메뉴권한 화면에서 권한 부여. |

## 6. 알아둘 제한 (이번 시연 버전)

- 완제품 **출하**, **외주정산**(가공비 정산), **선적(Billing) 시점 매입 인식**, **전자결재 연동**은 아직 없습니다(다음 단계).
- 이전 화면은 정방향(앞 공정 → 뒤 공정)만 만듭니다(역이전은 DB에는 준비돼 있음).
- 웨이퍼 입고는 "공급처 직송 도착 등록"(작업지시와 무관, 작업지시가 나중에 LOT 배정)까지만 있습니다(선적/Billing 시점 매입 인식, 자사 창고 경유 후 외주 출고는 다음 단계).
- 라우팅의 공정 순서 변경(위/아래 이동)은 없습니다(행을 지우고 다시 추가).
